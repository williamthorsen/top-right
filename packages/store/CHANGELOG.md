# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 — 2026-11-14

### 🎉 Features

- Adds the `@top-right/store` package, which declares the async `Store` interface for scores, status overrides, and visits and exports from `@top-right/store/testing` a conformance suite that each implementation runs against itself. (#20)
- Score the backlog with an agent and review its scores on the chart (#21)

  Adds a `top-right` CLI through which an agent writes scores for the open issues, and adds a review to the chart that marks each agent score, including one that replaced a score of the author's, until the author keeps or corrects it.

- Adds a Settings page at `/settings` to the local host for editing the labels that assign each work type and each repository's abbreviation, which the host saves per GitHub user and applies to the chart's borders and ids, with a saved mapping replacing the default mapping whole and Settings refusing a label that two work types list. (#31)
- Score urgency and value on four named levels (#56)

  Replaces the 1-to-5 urgency and impact scores with four named levels per axis and renames the impact axis to value, across the chart, the host's API, the `top-right` CLI, and the store. The first run against an existing store deletes every saved score, effort and progress included, so the items must be scored again.

- Adds a section to the Settings page that edits the labels that supply each urgency and value level, and refuses a label listed under two levels. (#57)
- Derive effort from repo labels (#59)

  Lets an issue's label supply its effort, by default one of `effort:1` through `effort:13`, so that the chart draws the issue's circle at that size before anyone scores the issue in the app. Adds an Effort section to the Settings page for mapping other labels to each point value, and keeps a score-label mapping saved before this change loading, with the default effort labels.

- Write urgency, value, and effort to labels (#61)

  Makes the local host write the urgency, value, and effort that the author sets or keeps on the chart to the issue's GitHub labels, so that the app and GitHub no longer disagree about an item's level. Keeps the scores that an agent writes through `top-right write-scores` in the app's store and out of the labels until the author keeps or corrects them.

- Adds a Collections section to the Settings page, in which a user creates, renames, edits, and deletes named groups of the configured repositories and chooses a default collection, and saves both per user in the store. (#78)

### 📦 Dependencies

- Upgrades Node.js from 24 to 26 by pinning 26.13.1 in `.tool-versions`, raising the `engines.node` floor to `>=26` in the root and every workspace manifest, and moving `@types/node` in the catalog from 24.19.2 to 26.6.6. (#105)
