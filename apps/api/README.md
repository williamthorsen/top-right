# API

A Node.js API that runs its TypeScript sources directly under Node's type stripping, without a build step.

Run it with `pnpm run start`.

To start a new app from this one, follow [Starting an app or a library from a template](../../docs/new-package.md).

<!-- section:release-notes --><!-- /section:release-notes -->

## Scripts

Workspace scripts (`check`, `lint`, `test`, `typecheck`) are run with `nmr` — see [Running scripts](../../README.md#running-scripts) in the root README. Run `nmr` from this directory to list this package's scripts.
