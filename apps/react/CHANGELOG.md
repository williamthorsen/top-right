## 1.3.1 — 2026-11-07

### ♻️ Refactoring

- Moves the api, cdk, chrome, nextjs, and react starters from `packages/` to `apps/`, which `pnpm-workspace.yaml` now declares alongside `packages/*`, and keeps `packages/` for the `_workspace` library scaffold. (#180)

### 📦 Dependencies

- Upgrade dependencies to their latest trusted releases (#183)

  Upgrades the dependencies and the `.tool-versions` pins to their latest releases, holding `lefthook` at 2.2.1 because 2.2.2 was published without provenance. Adapts the repo to the breaking first-party upgrades, mainly by making the drift kit's completeness check read readyup's `sources` list and by replacing the removed `rdy run --packages` flag with `rdy run --sources` in the docs.

- Replaces `jsdom` 30.1.3 with `happy-dom` 21.0.4 in the catalog and in the `react` and `nextjs` apps, whose Vitest configs and `@vitest-environment` control comments now select `happy-dom` as the test environment. (#201)
